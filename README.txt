# Cheang Oun Garage — Link Page

## Files
- index.html
- style.css
- script.js
- assets/garage.jpg

## Run on PC
1. Open the folder.
2. Double-click `index.html`.
3. The page opens in Chrome/Edge.
4. Test Facebook, Telegram, Google Maps and Call buttons.

## Edit contact information
Open `index.html` and change the `href` values:
- Facebook
- Telegram
- Google Maps
- Phone

## Publish online
Upload the whole folder to GitHub Pages, Netlify, or another static hosting service.
